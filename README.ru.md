# neuron explorer

[English](README.md) · **Русский**

Инструмент исследования нейронов с приоритетом стиринга для Qwen3.5-4B. Каждый нейрон MLP в слое толкается вверх и
вниз на нескольких промптах, каждая генерация сохраняется, а обозреватель раскладывает результаты поверх 3D-вида
модели.

![neuron explorer](explorer.png)

## Обозреватель

    uv sync
    uv run python explorer/server.py        # http://localhost:8791

Читает прогоны sweep из `runs/` и статистику по слоям из `stats/` — и то и другое создаёт sweep, описанный ниже;
кэши в `explorer/cache/` поставляются вместе с репозиторием. Загружает Qwen3.5-4B локально (MPS, CUDA или CPU) для
живого чата со стирингом, линз, связей и живой инференции по вашему тексту.

Строки R- и J++-линз читают карты из [bubskee/qwen3.5-4b-r-jpp-lenses](https://huggingface.co/bubskee/qwen3.5-4b-r-jpp-lenses)
(Apache-2.0):

    hf download bubskee/qwen3.5-4b-r-jpp-lenses --local-dir explorer/cache/rjpp

- **карта**: слои модели в перспективе, внимание и MLP на каждом слое, по точке на нейрон. Наведение показывает
  steer-линзу и R-линзу нейрона; клик открывает его; клик по подписи слоя показывает его лист анфас. `записи`
  размещает рядом нейроны с похожими столбцами down-проекции.
- **список**: юниты, упорядоченные по массе словесного кластера против контролей со случайными направлениями;
  `линза` ищет токен в steer-, R- и logit-линзах, `активации` прогоняет ваш текст через модель и фильтрует нейроны
  по активации.
- **нейрон**: генерации со стирингом по каждому промпту и дозе, трёхколоночный многоходовой чат со стирингом (−, 0, +),
  линзы и связи, имя, а также места срабатывания на веб-тексте: его сильнейшие контексты FineFineWeb для каждого знака,
  где каждый токен закрашен активацией нейрона, и домены, в которых он концентрируется.
- **эмбеддинги**: UMAP генераций слоя с раскраской по нейрону, промпту, дозе или типу.
- **язык**: при первом визите интерфейс следует языку браузера; меню справа в шапке переключает английский,
  упрощённый китайский и русский (выбор сохраняется в этом браузере). Переводы лежат в
  `explorer/static/i18n.js`.
- **Claude** (четвёртая вкладка панели нейрона или ручка у правого края): чат, запускающий CLI `claude` (установленный
  и авторизованный) с обозревателем в роли MCP-сервера (`explorer/agent_mcp.py`). Он читает нейроны, конусы и линзы,
  запускает живую модель (стиринг, активации, логвероятности следующего токена, абляции), двигает карту, список и
  подсветку, а также имеет файловые инструменты и оболочку в вашей домашней папке. Его промпт — `explorer/agent_prompt.md`
  плюс `explorer/agent_methodology.md` и `explorer/agent_prompt.local.md`, если он есть (не отслеживается, для ваших
  дополнений); модель выбирает `EXPLORER_CLAUDE_MODEL`. Сервер отвечает только страницами и инструментами на этой машине.

## Sweep

Запускается на GPU-поде с CUDA 13 с форком vLLM для стиринга ([RhizoNymph/vllm](https://github.com/RhizoNymph/vllm)).

    bash sweep/setup_pod.sh                                   # форк, зависимости, модель; пишет /workspace/env.sh
    python sweep/neuron_stats.py --layers 22 --tokens 2000000 --out stats/q35-4b
    python sweep/steer_sweep.py --stats stats/q35-4b_L22.npz --design main_rel --dose-unit rel \
        --neurons all --random-controls 256 --run q35-4b-L22
    sweep/run_depth.sh "4 9 13 17" 384 64                     # sweep случайного подмножества по нескольким слоям

Дозы `main_rel` — доли медианной нормы остатка на выходе слоя: {who, snake, orange} × {−0.7, +0.5, +0.8}
и {free} × {+3}, плюс один нестиренный базовый прогон на промпт.

| скрипт | результат |
|---|---|
| `sweep/neuron_stats.py` | экстремумы активации по нейрону для режимов знака, down-столбцы, нормы остатка |
| `sweep/steer_sweep.py` | `runs/<run>.jsonl`: текст, id токенов, логвероятности, top-k на каждом шаге; опциональные захваты активаций |
| `sweep/rank.py` | `runs/<run>.units.jsonl`: характерные слова, масса кластера, перцентиль против контролей |
| `sweep/steer_lens.py` | `stats/steer_lens_L{l}.npz`: Δlogprob и KL следующего токена для толчков ±0.8 по каждому нейрону |
| `sweep/depth_report.py` | `runs/depth_report.json`: доля нейронов выше контролей по слою, связность, топ-юниты |
| `sweep/shift.py` | сдвиг слов против контролей, учитываются все слова |
| `sweep/merge_runs.py` | объединяет осколки прогонов одного слоя |
| `sweep/check_equivalence.py` | согласие стиринга и захвата между HF и vLLM |
| `sweep/bench.py`, `sweep/peek.py` | условия пропускной способности; терминальные представления прогона |
| `explorer/build_embeddings.py` | `runs/<run>.umap.json` |
| `explorer/build_layout.py` | `explorer/cache/layout_writes.npz` |
| `explorer/build_connections.py` | `explorer/cache/connections.npz`: 24 сильнейшие связи прямого пути вверх и вниз для каждого нейрона |
| `sweep/fit_input_lens.py` | `S.pt`: обученная входная карта S_L (эмбеддинги токенов в остаток, который читает каждый MLP, слои 0–31), правила RelP из safety-research/jpp_lens; шардируется по промптам, объединяется по `num_prompts`; скопируйте в `explorer/cache/slens/S.pt` |
| `explorer/build_s_index.py` | `explorer/cache/s_index.npz`: топ-токены S-линзы (сторона чтения) для каждого нейрона, оба полюса |
| `explorer/build_rjpp_index.py` | `explorer/cache/r_index.npz`, `jpp_index.npz`: топ-токены R- и J++-линз для каждого нейрона, оба полюса (нужен релиз R/J++ в `explorer/cache/rjpp/`) |
| `sweep/finefineweb.py` | `<out>/corpus.npz`, `urls.json`, `acts.npz`: сбалансированная по доменам выборка FineFineWeb (около 20M токенов по 66 доменам) и топ-контексты каждого нейрона по знаку плюс статистика активаций по доменам; скопируйте три файла в `explorer/cache/ffw/` |
| `sweep/capture_prefill.py` | `captures/<run>.mlp_in.npy`: вход MLP на последнем токене промпта на слоях захвата прогона, со стирингом |

`research_log.md` хранит находки и рассуждения; `NOTES.md` — исходные заметки.
